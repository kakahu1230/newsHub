# NewsHub

NewsHub is a small news aggregation tool that fetches headlines from multiple sources, parses their content, deduplicates similar stories, categorizes them, and presents the results in a searchable dashboard.

## Project structure

```
newsHub/
├── data/
│   ├── processed/          # Generated JSON payloads for the UI
│   └── raw/                # Cached HTML responses per source
├── scripts/
│   └── refresh.py          # Command line refresh utility
├── src/news_hub/
│   ├── categorize/         # Category classifier
│   ├── dedup/              # Similarity detection and merging
│   ├── fetch/              # HTTP client with caching and throttling
│   ├── parse/              # Parsers per source
│   ├── presentation/       # Flask app powering the dashboard
│   ├── config.py           # Source configuration
│   ├── models.py           # Data models shared across modules
│   └── pipeline.py         # ETL orchestration helpers
├── static/                 # Front-end assets
├── templates/              # HTML templates for the dashboard
└── requirements.txt
```

## Getting started

1. **Install dependencies**

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   export PYTHONPATH=src
   ```

2. **Refresh data**

   The refresh script fetches HTML from each configured source, caches the raw responses, parses them, deduplicates the combined stories, applies keyword-based categorization, and exports the normalized feed.

   ```bash
   python scripts/refresh.py --force
   ```

   Use `--print` to emit the processed stories to stdout for quick inspection.

3. **Run the dashboard**

   ```bash
   flask --app news_hub.presentation.web:app run --reload
   ```

   The dashboard displays the categorized stories, supports searching headlines and summaries, and allows filtering by category. All processed data is read from `data/processed/stories.json` generated by the refresh step.

## Data sources

The current implementation pulls headlines from:

- [Reuters World News](https://www.reuters.com/world/)
- [AP News](https://apnews.com/hub/ap-top-news)
- [Defense One](https://www.defenseone.com/)
- [TechCrunch](https://techcrunch.com/)

## Automation

Schedule regular refreshes with cron or a task scheduler of your choice. For example, to update every hour using cron:

```
0 * * * * /path/to/venv/bin/python /path/to/newsHub/scripts/refresh.py --force
```

## Reproducibility and caching

NewsHub stores raw HTML in `data/raw/` with timestamps. Subsequent runs reuse the most recent cache unless `--force` is provided, ensuring repeatable processing and resilience against transient network errors.
